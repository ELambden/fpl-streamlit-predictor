Pipeline

Self-contained data, renewable each gameweek

The repository commits processed app-ready data so the portfolio loads without a private service. A scheduled GitHub Actions workflow can fetch the public FPL API, rebuild projections, regenerate static metadata, run tests, and commit the updated snapshot.

Machine learning

Explainable before clever

The first model is an interpretable fixture-adjusted projection blend with room for Ridge, ElasticNet, and tree baselines once historical gameweek labels are added. The app shows feature influence and baseline lift alongside recommendations.

Optimization

FPL rules as constraints

The optimizer respects budget, positions, club limits, legal formations, captaincy, bench ordering, and transfer costs. It supports generic transfer discovery and optional squad-specific recommendations.

Portfolio fit

This project is designed as a companion to the StatsBomb recruitment explorer: similar editorial visual system, but a different technical proof point. StatsBomb demonstrates event-data profiling and static browser visualisation; this project demonstrates Streamlit, current data refresh, modelling, and decision optimization.
